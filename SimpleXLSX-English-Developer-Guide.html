1. What Is This

SimpleXLSX is a pure-PHP xlsx reader used to parse Microsoft Excel 2007+ .xlsx workbooks and extract cell data into PHP arrays.

Its core selling point can be stated in one sentence: it reads Excel using only the built-in SimpleXML + zlib, without depending on any extra PHP extensions.

What It Does

Capability Description
Reading cell values Text, numbers, booleans, dates, error values, rich text
Multiple worksheets Access by index/name, hidden sheet detection, active sheet detection
Style extraction Fonts, colors, fills, borders, alignment, row heights and column widths
Hyperlinks and comments External cell links, internal jumps, comment plain text
Streaming reads The readRows() generator, suitable for large files
HTML export toHTML() / toHTMLEx() one-step table conversion
Zero extension dependencies No php-zip, no php-excel, pure PHP decompression

What It Cannot Do

This matters more than "what it can do" — clarifying it up front can save you half a day:

Out of Scope Reason
Writing/generating xlsx Read-only library. For writing, use the companion SimpleXLSXGen
Reading the legacy .xls format A completely different binary format; use SimpleXLS
Calculating formulas Only returns the result values Excel cached at save time; formulas are not recalculated
Merged cell info Does not parse mergeCells; only the top-left cell of a merged region has a value
Images/charts/pivot tables All ignored
Conditional formatting, data validation Not parsed
Cell "raw rich-text runs" Rich text is concatenated into a single string (see parseRichText)
Reading .xlsb / encrypted files Neither the binary format nor encrypted ZIP is supported

One-sentence guidance: if your need is "a user uploads an Excel file and I read the table out of it into a database", SimpleXLSX is the most cost-effective choice (a few dozen KB, no dependencies, fast enough). If you need to "generate complex reports with charts" or "reproduce print styles precisely", go with PhpSpreadsheet.

2. Requirements and Installation

2.1 System Requirements

Requirement Description
PHP >= 5.5 (verified working on PHP 8.3; PHP 5.5+ uses a Generator-compatible style)
ext-simplexml Required, for parsing XML
ext-zlib Required, gzinflate() decompresses ZIP entries
ext-libxml Required
ext-mbstring Required (declared in composer), used for the func_overload compatibility branch

Note: ext-zip is not needed. The ZIP unpacking is hand-written by the author (see the unzip() method). That is why it runs on all kinds of cheap shared hosting.

2.2 Installation Method 1: Composer (Recommended)

composer require shuchkin/simplexlsx

Then:

require_once 'vendor/autoload.php';

use Shuchkin\SimpleXLSX;

if ( $xlsx = SimpleXLSX::parse('book.xlsx') ) {
    print_r( $xlsx->rows() );
} else {
    echo SimpleXLSX::parseError();
}

⚠️ Note: the autoload section of composer.json only registers src/SimpleXLSX.php: json "autoload": { "classmap": ["src/SimpleXLSX.php"] } SimpleXLSXEx.php is not registered in the classmap; it is loaded manually via require_once __DIR__.'/SimpleXLSXEx.php' when readRowsEx() is called. You don't need to do anything, but don't expect class_exists('Shuchkin\SimpleXLSXEx') to be true before rowsEx() has been called.

2.3 Installation Method 2: Direct Single-File Include

Suitable for environments where Composer cannot be installed:

require_once __DIR__ . '/src/SimpleXLSX.php';

use Shuchkin\SimpleXLSX;

SimpleXLSX.php is self-contained and does not depend on other files (unless you want to use rowsEx()).

2.4 Using in Frameworks

Laravel: once installed via Composer, use it directly — no ServiceProvider needed.

use Shuchkin\SimpleXLSX;

public function import(Request $request) {
    $request->validate(['file' => 'required|file|mimes:xlsx|max:10240']);
    $xlsx = SimpleXLSX::parse($request->file('file')->getRealPath());
    // ...
}

ThinkPHP / others: either require the file path or use the Composer autoload.

3.2 Three Ways to Open a File

// ① From a file path (most common)
$xlsx = SimpleXLSX::parse('/path/to/book.xlsx');
$xlsx = SimpleXLSX::parseFile('/path/to/book.xlsx');   // equivalent

// ② From binary data in memory
$data = file_get_contents('https://example.com/book.xlsx');
// or fetched from a database BLOB or Redis cache
$xlsx = SimpleXLSX::parseData($data);

// ③ Passing a URL directly also works (uses file_get_contents internally, subject to allow_url_fopen)
$xlsx = SimpleXLSX::parse('https://www.example.com/example.xlsx');

Relationship among the three (source-code truth):

public static function parse($filename, $is_data = false, $debug = false) // core
public static function parseFile($filename, $debug = false)  // → parse($filename, false, $debug)
public static function parseData($data, $debug = false)      // → parse($data, true, $debug)

Internally, parse() first calls unzip() then parseEntries(); it returns a SimpleXLSX object on success and false on failure.

3.3 Classic OOP Style

If you prefer "construct an object + check state" over "static factory + check for false":

$xlsx = new SimpleXLSX('books.xlsx');
if ( $xlsx->success() ) {
    foreach ( $xlsx->rows() as $r ) {
        // ...
    }
} else {
    echo 'xlsx error: ' . $xlsx->error();
}

Constructor signature: __construct($filename = null, $is_data = null, $debug = null).

Difference between the two styles: the static parse() returns false on failure and stores the error message in a static variable; the new style always returns an object, and you check with success(). Both call the same underlying unzip().

3.4 Debug Mode

ini_set('error_reporting', E_ALL);
ini_set('display_errors', 1);

if ( $xlsx = SimpleXLSX::parseFile('books.xlsx', true) ) {
    echo $xlsx->toHTML();
} else {
    echo SimpleXLSX::parseError();
}

With $debug = true enabled, every internal error() call additionally triggers trigger_error(..., E_USER_WARNING), making problems easier to locate.

4. Core Concepts: How an xlsx Is Read

To use this library well (especially for troubleshooting), it is worth spending 3 minutes understanding how it works.

4.1 An xlsx Is Essentially a ZIP

An .xlsx is just a ZIP archive with a changed extension, containing a bunch of XML files:

book.xlsx
├── _rels/.rels                        ← entry point, indicates where the workbook is
├── xl/
│   ├── workbook.xml                   ← worksheet list, names, order, active sheet
│   ├── _rels/workbook.xml.rels        ← mapping of rId → actual file
│   ├── sharedStrings.xml              ← shared string pool
│   ├── styles.xml                     ← fonts/fills/borders/number formats
│   ├── theme/theme1.xml               ← theme colors
│   └── worksheets/
│       ├── sheet1.xml                 ← the actual cell data
│       ├── _rels/sheet1.xml.rels      ← that sheet's hyperlinks/comments
│       └── ...

4.2 Parsing Flow (Mapped to Source-Code Methods)

SimpleXLSX::parse($file)
    │
    ├─ unzip($filename, $is_data)      ← hand-written ZIP unpacking; all entries are read into $this->package['entries']
    │                                     (not decompressed at this point; only compressed data + header info are stored)
    │
    └─ parseEntries()                  ← builds the indexes
         ├─ reads _rels/.rels → finds officeDocument → xl/workbook.xml
         ├─ iterates over the <sheet> elements in workbook.xml → $this->sheetMetaData[i] (name/sheetId/state/id)
         ├─ reads xl/_rels/workbook.xml.rels → dispatches by rId:
         │     worksheet    → $this->sheets[i] = SimpleXMLElement (and records sheetFiles[i])
         │     sharedStrings→ $this->sharedstrings[] = array of strings
         │     styles       → $this->styles + $this->nf + $this->cellFormats
         │     theme        → $this->theme
         └─ reads $this->activeSheet from <bookViews><workbookView activeTab="N"> in workbook.xml

4.3 Memory Model (Important)

This is where many people get tripped up:

  1. unzip() loads the entire file into memory in one file_get_contents() call;
  2. All ZIP entries (in compressed form) are kept entirely in the $this->package['entries'] array;
  3. Only when getEntryXML($name) is called does gzinflate() decompress; immediately after decompression, deleteEntry() removes the entry from the array (to save memory);
  4. But once sheet1.xml has been parsed by simplexml_load_string() into a SimpleXMLElement, it stays in memory.

Conclusion: peak memory is at least 2–3 times the file size, plus the XML object tree. readRows() only saves the "result array" layer; it cannot save the "whole-sheet DOM" layer. See Chapter 10 for details.

4.4 Cell Coordinates

  • A1 style (Excel notation) and [column index, row index] (0-based) convert to each other:
  • getIndex('AB12') → [27, 11] (verified)
  • SimpleXLSX::num2name(3) → 'C'
  • num2name(1) = 'A', num2name(27) = 'AA' (verified)

5. Full API Reference

All signatures below come from reflection extraction against the 1.1.19 source; parameter defaults match the source exactly.

5.1 Static Factory Methods

SimpleXLSX::parse($filename, $is_data = false, $debug = false)

Parameter Type Description
$filename string File path, URL, or — when $is_data=true — the xlsx binary content
$is_data bool true means the first parameter is data rather than a path
$debug bool When enabled, errors are reported via trigger_error

Returns: a SimpleXLSX object on success, false on failure.

$xlsx = SimpleXLSX::parse('book.xlsx');          // file
$xlsx = SimpleXLSX::parse($binary, true);        // in-memory data
$xlsx = SimpleXLSX::parse('a.xlsx', false, true);// debug

SimpleXLSX::parseFile($filename, $debug = false)

Equivalent to parse($filename, false, $debug). Clearer semantics; recommended.

SimpleXLSX::parseData($data, $debug = false)

Equivalent to parse($data, true, $debug). Use for database BLOBs / caches / network streams.

SimpleXLSX::parseError($set = false) / SimpleXLSX::parseErrno($set = false)

Reads (or sets) the error message/error code of the most recent parse().

if ( !$xlsx = SimpleXLSX::parse('x.xlsx') ) {
    echo SimpleXLSX::parseErrno() . ': ' . SimpleXLSX::parseError();
}

⚠️ These two methods use static local variables, which are globally shared state. When parsing multiple files in a row, always read them immediately after each parse(), or they will be overwritten by the next parse.

Verified output:

// Array( [0] => type tests [1] => second page [2] => hidden page )

print_r($x->sheetMeta());
// Array(
//   [0] => Array( [name] => type tests [sheetId] => 1 [state] => visible [id] => rId1 )

Finding an index by name (not provided by the library; write it yourself):

function sheetIndexByName(SimpleXLSX $xlsx, string $name): ?int {
    $map = array_flip($xlsx->sheetNames());
    return $map[$name] ?? null;
}

💡 The keys of the sheets array follow the order in which <sheet> elements appear in workbook.xml, and parseEntries() performs a ksort() at the end, so indexes stably correspond to the left-to-right tab order in Excel.

5.4 Reading Data (Core)

rows($worksheetIndex = 0, $limit = 0): array

The most commonly used method. Returns a two-dimensional array where each row is a numerically indexed array starting from column 0.

Parameter Description
$worksheetIndex Worksheet index, 0-based
$limit Maximum number of rows to return; 0 means no limit 
foreach ( $xlsx->rows() as $r ) {
    echo $r[0] . ' | ' . $r[1] . "\n";
}

Internal implementation: iterator_to_array($this->readRows(...), false), i.e. everything is expanded into an array at once.

Empty-row padding behavior: readRows() pads trailing empty rows according to the row count from dimension(). That means if Excel's <dimension> declares 100 rows but only 3 rows contain data, you will get 100 rows (the last 97 being arrays of empty strings).

readRows($worksheetIndex = 0, $limit = 0): Generator

Returns the same data as rows(), but as a generator, producing rows one at a time without occupying result-array memory.

foreach ( $xlsx->readRows() as $k => $r ) {
    fputcsv($fp, $r);
}

rowsEx($worksheetIndex = 0, $limit = 0): array

Extended version; each cell is an associative array with 16 fields (value + styles + hyperlinks + comments + formula, etc.). See Chapter 6 for details.

The first call require_onces SimpleXLSXEx.php and constructs a SimpleXLSXEx instance (cached in $xlsx->rowsExReader).

readRowsEx($worksheetIndex = 0, $limit = 0): Generator

The generator version of rowsEx().

🔴 Verified bug: $limit does not work when it is smaller than the sheet's row count (it returns the full row count, the extra ones being empty rows). See Pitfall 1 for details. Count and break yourself.

getCell($worksheetIndex = 0, $cell = 'A1'): mixed

Gets the value of a single cell by Excel coordinate.

echo $xlsx->getCell(0, 'B2');     // The Hobbit
echo $xlsx->getCell(0, [1, 2]);   // equivalent, [column index, row number]; column 0-based, row 1-based

⚠️ Performance warning: the source code comment says outright VERY SLOW!. Internally it performs a whole-table XPath scan via $ws->sheetData->xpath("row/c[@r='B2']"), rescanning on every call. Never use it inside a loop. To fetch a batch of cells, call rows() once and index into it.

Returns null when the cell is not found, and false when the worksheet does not exist.

dimension($worksheetIndex = 0): array

Returns [number of columns, number of rows].

list($cols, $rows) = $xlsx->dimension(0);

It reads <dimension ref="A1:E3"> first; when that is unavailable it falls back to iterating over the entire sheetData to compute the maximum values (slow).

⚠️ The official README itself says // don't trust dimension extracted from xml. In xlsx files generated by some tools (e.g. certain Java/Python libraries), the dimension may be inaccurate. If the column count is too large, you will get a bunch of empty columns.

getIndex($cell = 'A1'): array

'AB12' → [27, 11] (0-based column, 0-based row). Returns [-1, -1] on parse failure.

value($cell)

Takes a <c> SimpleXMLElement node and returns its PHP value. This is the core method of type mapping (see Chapter 7). Business code generally does not need to call it directly.

5.5 HTML Output

toHTML($worksheetIndex = 0): string

echo SimpleXLSX::parse('book.xlsx')->toHTML();

Output looks like:

<table class=excel><tr><td nowrap>ISBN</td><td nowrap>title</td>...</tr></table>
  • Values are escaped with htmlspecialchars($c, ENT_QUOTES)
  • Empty cells output &nbsp

toHTMLEx($worksheetIndex = 0): string

The styled version. The first row uses <th>, the rest use <td>, and each cell carries inline style:

<table class=excel><tr><th style="color: #000000;font-family: Calibri;font-size: 17px;width: 5.17em;" nowrap>ISBN</th>...</tr></table>
  • Column width conversion: width: round($width * 0.47, 2) . 'em'
  • Row height conversion: height: round($height * 1.3333) . 'px' (only output on the first column of each row)
  • Line breaks converted to <br>

⚠️ The official documentation states the signature as toHTML($worksheetIndex = 0, $limit = 0), but the source code actually has only 1 parameter (verified via reflection: toHTML parameter count = 1, toHTMLEx = 1). Passing a second argument won't raise an error (PHP allows it), but it has no effect. To limit rows, loop over readRowsEx() yourself and count to break out (note that $limit in readRowsEx() is also broken — see Pitfall 1).

6. rowsEx() Cell Fields in Detail

Each cell returned by rowsEx() / readRowsEx() is an associative array with the following structure (16 fields, verified):

[
    'type'    => 's',                 // Cell data type
    'name'    => 'A1',                // Excel coordinate
    'value'   => 'ISBN',              // Parsed PHP value
    'href'    => '',                  // Hyperlink (external URL or internal location)
    'f'       => '',                  // Formula source text (without =)
    'format'  => 'General',           // Number format string
    's'       => 0,                   // Style index → $xlsx->cellFormats[0]
    'css'     => 'color: #000000;...',// Generated CSS string
    'r'       => 1,                   // Row number (1-based)
    'hidden'  => false,               // Whether the row or column containing this cell is hidden
    'width'   => 13.7109375,          // Column width (Excel custom units)
    'height'  => 0,                   // Row height (points, pt)
    'comment' => 'This is a comment', // Plain text of the cell comment
]

Field-by-Field Explanation

Field Type Description and Notes
type string Raw t attribute: s (shared string) str (formula string result) b (boolean) e (error) inlineStr (inline text) n/'' (number) d (ISO date). An empty string type is normal, meaning number or general
name string e.g. B2. Even empty cells get a correct coordinate filled in
value mixed Parsed value; types are covered in Chapter 7
href string Hyperlink. External links are full URLs; internal jumps look like Sheet1!A1. No protocol whitelist validation is performed; you must filter it yourself before outputting to HTML (see Chapter 12)
f string Formula source text, e.g. B3*2 (without the leading =). Note: for cells with formulas, value is Excel's cached result, not computed on the fly
format string Number format code, e.g. YYYY-MM-DD HH:MM:SS, 0.00%, #,##0.00
s int Style index. Note that in the source code, when s is 0 it falls back to the column style cols[$curC]['s']
css string Pre-generated by SimpleXLSXEx::readXfs(). Contains an accumulation bug, see Chapter 13
r int Row number, 1-based
hidden bool Row hidden or column hidden; true if either is true (tested: after hiding row 4, all cells in that row have hidden=true)
width float Column width in Excel custom units (≈ character width). Only has a value when customWidth is true, otherwise 0
height float Row height in points (pt = 1/72 inch). Only has a value when customHeight is true
comment string Plain text of the comment. Tested: Chinese comments are returned correctly

Type Detection Logic (Key Points from the Source Code)

// 1) When type is empty or n, the number format string in the style decides whether it is a date
if ($dataType === '' || $dataType === 'n') {
    $s = (int)$cell['s'];
    if ($s > 0 && isset($this->cellFormats[$s])) {
        if (array_key_exists('format', $this->cellFormats[$s])) {
            $format = $this->cellFormats[$s]['format'];
            // After stripping quoted literals, if the format string contains m (month/minute), treat it as a date
            if ($format && preg_match('/[mM]/', preg_replace('/"[^"]+"/', '', $format))) {
                $dataType = 'D';
            }
        }
    }
}

// 2) Default branch: string, converted to a number when possible
$value = (string)$cell->v;
if (is_numeric($value)) {
    if ($value == (int)$value)   $value = (int)$value;
    elseif ($value == (float)$value) $value = (float)$value;
}

This means:

  1. Date detection relies on "whether the format code contains the letter m". If a numeric column in a sheet is mistakenly given a custom format containing m, it will be incorrectly converted to a date. Conversely, a date column set to General will return an Excel serial number as a float (e.g. 44613.0) instead of a date.
  2. Leading zeros are lost. Something like 007 (treated as a number) becomes 7. Phone numbers, ID numbers, and postal codes must be formatted as text in Excel, otherwise SimpleXLSX returns int/float. This is the number one source of data accidents when importing into systems.
  3. Large integer precision: beyond PHP's int range or with decimals it becomes a float; 1234567890123456789 may turn into 1.2345678901235E+18.

About "Time Only"

In Excel, a time without a date (e.g. 13:41:00) is stored as 0.570138... (integer part 0). unixstamp() takes a special branch for d == 0:

$t = (abs($d) > 0) ? ($d - 25569) * 86400 + round($t * 86400) : round($t * 86400);

The result is based on the Unix epoch (1970-01-01), so 13:41 → '1970-01-01 13:41:00' (confirmed by testing).

Practical handling: take only the time part.

$val = $cell['value'];               // '1970-01-01 13:41:00'
$time = substr($val, 11);            // '13:41:00'

About Formulas

SimpleXLSX does not evaluate formulas; it reads the cached result Excel saved into the file (the <v> inside <c><f>B3*2</f><v>1236</v></c>).

Testing revealed that xlsx files generated by openpyxl / some non-Excel tools do not write cached values; in that case value is an empty string and only f has content.

Recommendation:

foreach ($xlsx->rowsEx() as $row) {
    foreach ($row as $c) {
        $v = $c['value'];
        if ($v === '' && $c['f'] !== '') {
            // Formula cell without a cached value
            $v = null; // or flag for manual handling / recompute yourself
        }
    }
}

8. Dates and Times in Depth

8.1 The Nature of Excel Dates

An Excel date is a floating-point number: the integer part is the "number of days since 1899-12-30" (the 1900 system), and the decimal part is the fraction of the day. For example, 42472.570138889 = 2016-04-12 13:41:00.

Why 1899-12-30 and not 1900-01-01? Because of Excel's famous "1900 is a leap year" bug. The 25569 in unixstamp() is the number of days between 1899-12-30 and 1970-01-01.

8.2 Conversion Formula

public function unixstamp($excelDateTime) {
    $d = floor($excelDateTime);      // days
    $t = $excelDateTime - $d;        // time fraction of the day
    if ($this->date1904) { $d += 1462; }   // 1904 system: add 1462 days
    $t = (abs($d) > 0) ? ($d - 25569) * 86400 + round($t * 86400) : round($t * 86400);
    return (int)$t;
}

The result is then formatted with gmdate($this->datetimeFormat, $ts) — note it is gmdate(), not date(), i.e. the timestamp is interpreted in UTC.

8.3 Four Usages

$xlsx = SimpleXLSX::parse('book.xlsx');

// ① Default: ISO format (can be stored directly in MySQL DATETIME)
echo $xlsx->getCell(0, 'C2');   // 2016-04-12 13:41:00

// ② Custom format
$xlsx->setDateTimeFormat('d.m.Y H:i');
echo $xlsx->getCell(0, 'C2');   // 12.04.2016 13:41

// ③ Unix timestamp
$xlsx->setDateTimeFormat('U');
$ts = $xlsx->getCell(0, 'C2');  // 1645401600 (string)
echo gmdate('Y-m-d', $ts);      // 2016-04-12

// ④ Raw Excel serial number (give up automatic conversion)
$xlsx->setDateTimeFormat(null);
$xd = $xlsx->getCell(0, 'C2');  // 42472.570138889 (float)
echo gmdate('m/d/Y', $xlsx->unixstamp($xd));  // 04/12/2016

Confirmed by testing (same cell, four settings):

NULL             => 44613.0                      (float)
'Y-m-d H:i:s'    => '2022-02-21 00:00:00'        (string)
'd.m.Y H:i'      => '21.02.2022 00:00'           (string)
'U'              => '1645401600'                 (string)

Note that 'U' returns a string, not an integer; you need an (int) cast.

8.4 Time Zone Pitfall

gmdate() means: a 2016-04-12 13:41 written in Excel comes out as 2016-04-12 13:41:00, without any offset caused by the server time zone. This is usually exactly what you want (what you see in Excel is what you get).

Conversely, if you need to interpret it in a specific time zone, you must add the offset yourself:

$xlsx->setDateTimeFormat('U');
$ts = (int)$xlsx->getCell(0, 'C2');
$local = date('Y-m-d H:i:s', $ts + 8 * 3600);  // display in UTC+8

8.5 The 1904 Date System

Old Mac Excel files may use the 1904 system. The library automatically detects <workbookPr date1904="1"> in workbook.xml and sets $xlsx->date1904 = 1.

When manual intervention is needed (the property is public):

$xlsx->date1904 = 1;   // force the 1904 system

If you find all dates are 4 years and 1 day later than they should be, this is the issue.

8.6 Helper for Identifying Date Columns

rows() only gives you values; it doesn't tell you which column is a date. Use the format from rowsEx():

function isDateCell(array $cell): bool {
    if ($cell['type'] === 'd') return true;
    if (!in_array($cell['type'], ['', 'n'], true)) return false;
    $fmt = preg_replace('/"[^"]+"/', '', $cell['format']);
    // Contains any of y/m/d/h/s and is not a pure numeric format
    return (bool)preg_match('/[ymdhs]/i', $fmt);
}

9. The Style System (SimpleXLSXEx)

9.1 Load Timing

SimpleXLSXEx is lazily loaded: it is only require_onced and instantiated the first time rowsEx() / readRowsEx() / toHTMLEx() is called, and is then cached in $xlsx->rowsExReader.

If you only use rows(), this class is never loaded at all — zero overhead.

9.2 What the Constructor Does

9.3 Color Parsing getColorValue()

Supports three Excel color notations with this priority:

  1. rgb="FFCCBBAA" → take the last 6 digits (drop the alpha)
  2. indexed="N" → look up the built-in palette SimpleXLSXEx::$IC (65 colors)
  3. theme="N" → look up the theme palette

Finally, if a tint attribute is present, a tint blend is applied (interpolation toward white/black).

9.5 Font Size Conversion

$css .= 'font-size: ' . (round($cf['f-size'] * 1.3333) + 2) . 'px;';

Excel font sizes are in points (pt); here it is roughly converted to px as pt × 1.3333 + 2 (1pt ≈ 1.333px). So 11pt → 17px, 14pt → 21px.

9.6 Borders

Excel's 14 border styles are simplified into two CSS styles: solid and dashed (dashed/dashDot/dashDotDot → dashed, all other non-none styles → solid), the width is uniformly thin, and the color is taken from the corresponding direction's color.

In other words: medium, thick, double, and hair all look the same in HTML. This is an intentional simplification — don't expect pixel-perfect reproduction.

9.7 Building CSS Yourself (Bypassing the Built-in css Bug)

If the built-in css field is not good enough (see the accumulation bug in Chapter 13), you can read cellFormats and assemble it yourself:

function buildCss(SimpleXLSX $xlsx, int $s): string {
    $f = $xlsx->cellFormats[$s] ?? [];
    $css = '';
    if (!empty($f['color']))    $css .= 'color:#' . $f['color'] . ';';
    if (!empty($f['bgcolor']))  $css .= 'background-color:#' . $f['bgcolor'] . ';';
    if (!empty($f['f-b']))      $css .= 'font-weight:bold;';
    if (!empty($f['f-i']))      $css .= 'font-style:italic;';
    if (!empty($f['align']))    $css .= 'text-align:' . $f['align'] . ';';
    if (!empty($f['valign']))   $css .= 'vertical-align:' . $f['valign'] . ';';
    if (!empty($f['f-size']))   $css .= 'font-size:' . (round($f['f-size'] * 1.3333) + 2) . 'px;';
    return $css;
}

10. Large Files and Memory Optimization

10.1 Official Benchmark Data

From CHANGELOG 1.0.12, the author's measurements:

Method Memory for 100K rows
rowsEx() ~880 MB
readRowsEx() ~162 MB

More than a 5x difference. The reason is that rows() / rowsEx() expand the entire sheet into a huge two-dimensional PHP array (each element of a PHP array costs about 80–100 bytes; 100K rows × 10 columns is 1 million zvals).

10.2 Where the Memory Goes

Total memory ≈ file size (raw binary)
       + compressed data of all ZIP entries (package['entries'])
       + SimpleXMLElement trees of parsed worksheets (the biggest chunk)
       + shared strings array
       + result array (only for rows/rowsEx)

readRows() only cuts the last item.

10.3 Optimization Checklist

① Prefer generators

// ❌ Bad: the whole sheet goes into memory
foreach ($xlsx->rows() as $r) { ... }

// ✅ Good: row-by-row output
foreach ($xlsx->readRows() as $r) { ... }

② Stream to the destination; don't accumulate

$f = fopen('out.csv', 'wb');
fwrite($f, chr(0xEF) . chr(0xBB) . chr(0xBF));  // UTF-8 BOM so Excel opens Chinese without garbling
foreach ($xlsx->readRows() as $r) {
    fputcsv($f, $r);
}
fclose($f);

③ Process in batches and release

$pdo->beginTransaction();
$stmt = $pdo->prepare('INSERT INTO t (a,b,c) VALUES (?,?,?)');
$i = 0;
foreach ($xlsx->readRows() as $k => $r) {
    if ($k === 0) continue;                 // skip the header row
    $stmt->execute([$r[0], $r[1], $r[2]]);
    if (++$i % 1000 === 0) {
        $pdo->commit(); $pdo->beginTransaction();
    }
}
$pdo->commit();

④ Raise the memory limit (last resort)

ini_set('memory_limit', '512M');

⑤ Realistic advice for very large sheets

If an xlsx exceeds 20–30 MB or 500K rows, SimpleXLSX is not the right tool, because the XML DOM must reside entirely in memory. In that case you should:

  • At the upload step, ask users to switch to CSV;
  • Or write your own streaming SAX parser (e.g. XMLReader + expand());
  • Or use PhpSpreadsheet with setReadDataOnly(true) + chunked reading (also memory-hungry, but slightly better).

10.4 The $limit Parameter (⚠️ Inconsistent Behavior Across Methods)

rows() / readRows() / rowsEx() / readRowsEx() all declare $limit, but testing shows only the first three are reliable:

$xlsx->rows(0, 100);        // ✅ only the first 100 rows
$xlsx->readRows(0, 100);    // ✅ works
$xlsx->rowsEx(0, 100);      // ✅ works (internally uses iterator_to_array)
$xlsx->readRowsEx(0, 100);  // ❌ broken, returns all rows

readRows() boundary behavior observed in testing (sheet has 13 rows total):

$limit Rows returned
0 13 (unlimited)
1 1
2 2
99 13

Under the same conditions, readRowsEx() returns 13 rows regardless of passing 1/2/3/5. Cause and workaround: see Pitfall 1.

⚠️ toHTML() and toHTMLEx() don't have a $limit parameter at all (only 1 parameter in the source).

12. Security Considerations

12.1 XSS: Values Are Escaped, but href Is Not

Good news: toHTML() and toHTMLEx() apply htmlspecialchars($v, ENT_QUOTES) to cell values.

Bad news: the href field returned by rowsEx() has no protocol validation whatsoever. If you build the HTML yourself:

// ❌ Dangerous: href could be javascript:alert(1)
echo '<a href="' . $cell['href'] . '">link</a>';

// ✅ Correct: whitelist validation
function safeHref(string $href): string {
    if (preg_match('#^https?://#i', $href)) return $href;
    if (preg_match('#^mailto:#i', $href))   return $href;
    if (preg_match('/^[^!]+![A-Z]+\d+$/', $href)) return ''; // internal jump, not expressible in HTML
    return '';
}
echo '<a href="' . safeHref($cell['href']) . '">link</a>';

12.2 CSS Injection (CVE-2024-55878)

Historical versions had a vulnerability allowing CSS injection via styles (GHSA-x6mh-rjwm-8ph7). Fixed in 1.1.19 with:

  • Font names forced through a whitelist: preg_match('/^[a-zA-Z0-9 ]+$/', $name), falling back to Calibri if invalid
  • Colors forced to 6-digit hex: preg_match('/^[A-F0-9]{6}$/', $c)
  • Alignment values taken only from a fixed mapping table

But if you inline the css field directly into style="", sanitizing it a second time is still recommended (especially when rendering user-uploaded files on the public web):

// Coarse filtering: keep only known-safe CSS properties
function sanitizeCss(string $css): string {
    $out = '';
    foreach (explode(';', $css) as $decl) {
        $decl = trim($decl);
        if (preg_match('/^(color|background-color|font-family|font-size|font-weight|font-style|text-decoration|text-align|vertical-align|border-(top|right|bottom|left)-(style|color|width)):/', $decl)) {
            $out .= $decl . ';';
        }
    }
    return $out;
}

A more thorough option: integrate HTMLPurifier.

12.3 XXE (XML External Entities)

The source code already handles this:

if (LIBXML_VERSION < 20900 && function_exists('libxml_disable_entity_loader')) {
    $_old = libxml_disable_entity_loader();
}
$entry_xmlobj = simplexml_load_string($entry_xml, 'SimpleXMLElement', LIBXML_COMPACT | LIBXML_PARSEHUGE);

libxml >= 2.9 does not load external entities by default, so no manual disabling is needed. The premise is that you are running a reasonably new libxml — don't run this bare on old systems like CentOS 6.

12.4 Decompression Bombs (Zip Bomb)

An xlsx is a ZIP, so in theory there is a zip bomb risk (1KB file decompressing to 10GB). SimpleXLSX does not enforce any decompression size limit.

Mitigation: limit file size before upload (e.g. ≤ 10 MB), and set memory_limit in PHP as a backstop.

12.5 Other

  • Don't trust dimension: a malicious file can declare A1:XFD1048576, causing readRows() to try to pad hundreds of millions of empty rows. Add your own row-count cap.
  • File names: don't build paths from the uploaded original file name (path traversal); generate your own file names.
  • Temp file lifecycle: PHP deletes uploaded temp files when the script ends; be sure to call move_uploaded_file() first.

13. Known Issues and Pitfall List

The following are behaviors I found by reading the source code in full + testing. They are not documented in the official docs, grouped by severity (🔴 High / 🟠 Medium / 🟢 Low).

🔴 Pitfall 1: The $limit Parameter of readRowsEx() Is Broken (Confirmed by Testing in 1.1.19)

Symptom: when $limit is less than the worksheet's row count, readRowsEx() ignores the limit and returns the full row count (the extras are all empty rows).

Test data (worksheet has 13 rows total):

$limit readRows() returns readRowsEx() returns
0 (unlimited) 13 13
1 1 ✅ 13 ❌
2 2 ✅ 13 ❌
3 3 ✅ 13 ❌
5 5 ✅ 13 ❌
13 13 ✅ 13 ✅
20 13 ✅ 13 ✅

Root cause: in SimpleXLSXEx::readRowsEx(), hitting the limit uses break, while SimpleXLSX::readRows() uses return:

// SimpleXLSX::readRows() —— correct
yield $r;
$_limit--;
if ($_limit === 0) { return; }        // ← ends the generator immediately

// SimpleXLSXEx::readRowsEx() —— bug
yield $cells;
$_limit--;
if ($_limit === 0) { break; }         // ← only breaks out of the foreach
// ...
while ($curR < $numRows) {            // ← still entered after break
    yield $emptyRow;                  //    keeps padding empty rows, and $_limit is already negative, so it will never hit 0 again
    $_limit--;
    if ($_limit === 0) { return; }
}

Impact: When you call rowsEx(0, 100) intending to "preview the first 100 rows", you actually get all rows of the entire sheet (including empty rows padded later), making memory usage and runtime spiral out of control on large files.

Workaround: Count rows yourself and break out; don't rely on $limit:

$n = 0;
foreach ($xlsx->readRowsEx(0) as $r) {      // no limit passed
    if (++$n > 100) break;
    // ...
}

✅ Fixed: The patch bundled with this documentation (see 17. Source-Code Bug Fix List) changed break to return. After the fix, the $limit of readRowsEx() behaves the same as readRows(), and $limit can be used directly.

🔴 Pitfall 2: Calling rowsEx() multiple times on the same instance makes CSS accumulate infinitely

Symptoms (verified by testing):

1st rowsEx B3.css = 'color: #000000;font-family: Calibri;font-size: 17px;text-align: right;×4'
2nd rowsEx B3.css = '... text-align: right;×8'
3rd rowsEx B3.css = '... text-align: right;×12'

Cause: In SimpleXLSXEx::valueEx(), the assignment is by reference:

$r['css'] = &$this->css[$r['s']];           // reference!
if (...) { $r['css'] .= 'text-align: right;'; }  // written into $this->css[$s] itself

Every time rowsEx()/toHTMLEx() is called, every cell that is "non-empty, unaligned, and not of text type" appends to the same shared string once more.

Impact: The output HTML grows longer and the stylesheet gets polluted (although duplicate CSS declarations are harmless semantically, the string keeps doubling).

Workarounds:

// Option A: parse fresh each time (simplest)
$xlsx1 = SimpleXLSX::parse($f); $a = $xlsx1->rowsEx();
$xlsx2 = SimpleXLSX::parse($f); $b = $xlsx2->rowsEx();

// Option B: deduplicate
$css = implode(';', array_unique(array_filter(explode(';', $cell['css'])))) . ';';

// Option C: don't use the built-in css; generate your own from cellFormats (see 9.7)

✅ Fixed: The bundled patch changed the reference assignment into a value copy ($r['css'] = isset($this->css[$r['s']]) ? ... : ''), so repeated calls on the same instance no longer accumulate.

🔴 Pitfall 2: toHTML() / toHTMLEx() has no $limit parameter

The README shows the signature as toHTML($worksheetIndex = 0, $limit = 0), but reflection on the source code shows only 1 parameter. Passing a second argument silently has no effect.

To limit the number of rows:

echo '<table>';
$i = 0;
foreach ($xlsx->readRowsEx(0, 100) as $r) {   // generator + limit
    echo '<tr>';
    foreach ($r as $c) { echo '<td>' . htmlspecialchars($c['value']) . '</td>'; }
    echo '</tr>';
}
echo '</table>';

✅ Fixed: The bundled patch added the $limit parameter to both methods and passes it through to readRows()/readRowsEx(). You can now call toHTML(0, 100) directly.

🟠 Pitfall 3: Formula cells may return an empty string

Formulas are not evaluated; only cached values are read. xlsx files not generated by Excel often lack cached values → value === ''. See Chapter 7 for details.

✅ Solved: The companion extension SimpleXLSXPro ships with a formula evaluation engine, so formulas without cached values can still be computed. See 18. Formula Evaluation for details.

🟠 Pitfall 4: Leading zeros / precision loss on long numbers

007 and 130123199001011234 stored as numbers in Excel get converted to int/float, losing both leading zeros and precision.

Must be fixed at the source: ask users to set these columns to "Text" format in Excel, or pad zeros after import according to your business rules:

$id = str_pad((string)$v, 18, '0', STR_PAD_LEFT);

🟠 Pitfall 5: Inaccurate dimension causes extra empty rows

After iterating over the real rows, readRows() still runs while ($curR < $numRows) yield $emptyRow;. If the row count declared in the XML dimension is far larger than the actual data, you'll receive a bunch of all-empty rows.

Defense:

$maxRows = 100000;
$n = 0;
foreach ($xlsx->readRows() as $r) {
    if (++$n > $maxRows) break;
    if (array_filter($r) === []) continue;   // skip all-empty rows
    // ...
}

🟡 Pitfall 6: getCell() is extremely slow

Internally it does an XPath full-table scan. The source code comment explicitly says VERY SLOW!. Fetching 1000 cells with getCell() causes noticeable lag. For batch retrieval, use rows() and access by index.

🟡 Pitfall 7: parseError() is global static state

static $error = false;
return $set ? $error = $set : $error;

When parsing multiple files in a loop, if one succeeds in the middle, parseError() is not cleared (the success path doesn't call parseError()). Therefore:

// ❌ After the second parse succeeds, you still read the first one's error
SimpleXLSX::parse('bad.xlsx');   // fails, sets error
SimpleXLSX::parse('good.xlsx');  // succeeds, does not reset error
echo SimpleXLSX::parseError();   // still shows bad.xlsx's error!

// ✅ Correct: read it only in the failure branch

✅ Fixed: The bundled patch added a $reset parameter to parseError()/parseErrno() and actively resets on the success branch of parse(). Verified after the fix: SimpleXLSX::parse('bad.xlsx') → after failure, parseError() = 'File not found bad.xlsx'; immediately after, parse('good.xlsx') succeeds → parseError() = false.

Alternatively, use new SimpleXLSX() + the $xlsx->error() instance method inside loops, which isolates state naturally.

🟡 Pitfall 8: rows() returns an empty array instead of an error when the worksheet doesn't exist

var_dump($xlsx->rows(9));   // array(0) {} — empty array, not false
echo $xlsx->errno();        // but errno is set to 6

So don't judge success by empty($rows) alone; check errno() or check sheetsCount() first.

🟡 Pitfall 9: Style index out of range triggers a PHP Notice

In valueEx():

$st = &$this->xlsx->cellFormats[$r['s']];

If the xlsx's cellXfs definitions are fewer than the s indexes referenced by cells, an Undefined offset notice is raised. In production it's advisable to disable notice display, or suppress it with @ before the call.

✅ Fixed: The bundled patch added an isset() guard before lookup; missing indexes are auto-filled with ['format'=>null,'align'=>0].

🟡 Pitfall 10: Merged cells are not returned

mergeCells is not parsed at all. In a merged region only the top-left cell has a value; the rest are empty. If you rely on the "fill" effect of merged cells, you need to handle it yourself:

$last = null;
foreach ($rows as $r) {
    $r[0] = $r[0] !== '' ? $r[0] : $last;   // simple forward fill
    $last = $r[0];
}

✅ Solved: The companion extension SimpleXLSXPro fully parses mergeCells; CSV/TSV/JSON split the value and copy it to every cell in the x*y range, and HTML outputs real colspan/rowspan. See 19. Merged Cells and Multi-Format Export for details.

🟢 Pitfall 11: ZIP64 limits

ZIP64 data descriptors are supported since 1.1.18, but a single entry larger than 4GB still returns error 6 "ZIP64 entry is too large to process". Normal xlsx files won't hit this.

🟢 Pitfall 12: Regex-based namespace prefix stripping

getEntryXML() uses a chain of regexes to strip XML namespaces:

$entry_xml = preg_replace('/xmlns[^=]*="[^"]*"/i', '', $entry_xml);
$entry_xml = preg_replace('/[a-zA-Z0-9]+:([a-zA-Z0-9]+="[^"]+")/', '$1', $entry_xml);
$entry_xml = preg_replace('/<[a-zA-Z0-9]+:([^>]+)>/', '<$1>', $entry_xml);

This is a "dirty but fast" approach. It may cause collateral damage on extremely non-standard XML. If you hit errno=3, you can dump the cleaned XML for troubleshooting.

🟢 Pitfall 13: Regex optimization for empty rows

On sheet XML, a regex removes rows where "the entire row is empty <c/>":

$entry_xml = preg_replace('/<row[^>]+>\s*(<c[^\/]+\/>\s*)+<\/row>/', '', $entry_xml, -1, $cnt);

Side effect: row numbers are no longer contiguous. rows() fills in empty rows (based on the y coordinate computed by getIndex()), so it's usually fine; but if you iterate over worksheet()->sheetData->row directly, be aware that row numbers have gaps.

function xlsxToAssocSafe(SimpleXLSX $xlsx, int $sheet = 0): array {
    $header = [];
    $rows   = [];
    foreach ($xlsx->readRows($sheet) as $k => $r) {
        if ($k === 0) {
            $seen = [];
            foreach ($r as $i => $h) {
                $h = trim((string)$h);

function xlsxToHtml(SimpleXLSX $xlsx, int $sheet = 0, int $limit = 0): string {

14.7 Upload and import into a database (complete example)

use Shuchkin\SimpleXLSX;

function importUsers(PDO $pdo, string $tmpFile): array {
    $xlsx = SimpleXLSX::parse($tmpFile);
    if (!$xlsx) {
        return ['ok' => false, 'msg' => SimpleXLSX::parseError()];
    }

    // Output uniformly in UTC, store directly as DATETIME
    $xlsx->setDateTimeFormat('Y-m-d H:i:s');

    $stmt = $pdo->prepare(
        'INSERT INTO users (name, phone, id_card, amount, created_at) VALUES (?,?,?,?,?)'
    );

    $ok = $fail = 0;
    $errors = [];

    $pdo->beginTransaction();
    foreach ($xlsx->readRows() as $k => $r) {
        if ($k === 0) { continue; }                     // skip the header row

        $name  = trim((string)($r[0] ?? ''));
        $phone = trim((string)($r[1] ?? ''));
        $idcard= trim((string)($r[2] ?? ''));
        $amount= is_numeric($r[3] ?? null) ? (float)$r[3] : null;
        $ctime = ($r[4] ?? '') ?: date('Y-m-d H:i:s');

        if ($name === '') { $errors[] = "Row {$k}: name is empty"; $fail++; continue; }

        $stmt->execute([$name, $phone, $idcard, $amount, $ctime]);
        $ok++;

        if ($ok % 500 === 0) { $pdo->commit(); $pdo->beginTransaction(); }
    }
    $pdo->commit();

    return ['ok' => true, 'imported' => $ok, 'failed' => $fail, 'errors' => array_slice($errors, 0, 20)];

14.8 Recommended wrapper class

Handle all of the pitfalls above in one go:

<?php
use Shuchkin\SimpleXLSX;

// Requires PHP 7.4+ (uses arrow functions and property type declarations)
class XlsxReader
{
    private SimpleXLSX $xlsx;
    private string $source;
    private bool $isData;
    private int $maxRows;

    public function __construct(string $pathOrData, bool $isData = false, int $maxRows = 100000)
    {
        $this->maxRows = $maxRows;
        $this->source  = $pathOrData;
        $this->isData  = $isData;
        $x = $isData ? SimpleXLSX::parseData($pathOrData) : SimpleXLSX::parse($pathOrData);
        if (!$x) {
            throw new RuntimeException(
                'XLSX parse failed [' . SimpleXLSX::parseErrno() . ']: ' . SimpleXLSX::parseError()
            );
        }
        $this->xlsx = $x;
    }

    /** Yield row by row, skipping all-empty rows automatically, with automatic rate limiting */
    public function rows(int $sheet = 0): Generator
    {
        $n = 0;
        foreach ($this->xlsx->readRows($sheet) as $r) {
            if (++$n > $this->maxRows) { return; }
            if (array_filter($r, static fn($v) => $v !== '' && $v !== null) === []) {
                continue;   // skip all-empty rows (defense against inaccurate dimension)
            }
            yield $r;
        }
    }

    /** Associative arrays with headers */
    public function assoc(int $sheet = 0): Generator
    {
        $header = null;
        foreach ($this->rows($sheet) as $r) {
            if ($header === null) {
                $header = array_map(
                    static fn($h, $i) => trim((string)$h) === '' ? "col_$i" : trim((string)$h),
                    $r, array_keys($r)
                );
                continue;
            }
            $row = [];
            foreach ($header as $i => $h) { $row[$h] = $r[$i] ?? null; }
            yield $row;
        }
    }

    /** Cells with styles; css accumulation bug and href security already fixed */
    public function rowsEx(int $sheet = 0): Generator
    {
        // Re-parse a clean instance to avoid css reference pollution (see Pitfall 2)
        $ex = $this->isData ? SimpleXLSX::parseData($this->source) : SimpleXLSX::parse($this->source);
        if (!$ex) { throw new RuntimeException(SimpleXLSX::parseError()); }

        $n = 0;
        foreach ($ex->readRowsEx($sheet) as $r) {
            if (++$n > $this->maxRows) { return; }
            foreach ($r as &$c) {
                $c['css']  = $this->dedupeCss($c['css']);
                $c['href'] = $this->safeHref($c['href']);
            }
            unset($c);
            yield $r;
        }
    }

    private function dedupeCss(string $css): string
    {
        $parts = array_filter(array_map('trim', explode(';', $css)));
        return implode(';', array_unique($parts)) . ';';
    }

    private function safeHref(string $href): string
    {
        return preg_match('#^(https?://|mailto:)#i', $href) ? $href : '';
    }

    public function sheetNames(): array { return $this->xlsx->sheetNames(); }
    public function sheetsCount(): int  { return $this->xlsx->sheetsCount(); }
    public function dimension(int $s = 0): array { return $this->xlsx->dimension($s); }
}

}

18. Formula Evaluation (XLSXFormula)

The original version does not evaluate formulas; it only reads the cached values written by Excel (the <v> inside <c><f>SUM(A1:A3)</f><v>60</v></c>). Once a file is generated by openpyxl / a custom program, the cached values are empty and all values are ''.

XLSXFormula is a pure-PHP formula evaluator that, together with SimpleXLSXPro, can compute results directly.

18.1 Basic Usage

use Shuchkin\SimpleXLSXPro;

$xlsx = SimpleXLSXPro::parse('demo.xlsx');

// 2) Evaluate an arbitrary formula (it does not have to be in the sheet)
echo $xlsx->calculate('IF(SUM(D3:D5)>700,"Excellent","Average")');   // Excellent

// 3) Iterate over all cells containing formulas
foreach ($xlsx->calculatedCells(0) as $coord => $info) {
    printf("%s %s => %s\n", $coord, $info['formula'], $info['value']);
}

// 4) Every cell in rowsPro() carries a calculated field
foreach ($xlsx->readRowsPro(0) as $row) {
    foreach ($row as $c) {
        if ($c['f'] !== '') {
            echo $c['name'], ' = ', $c['calculated'], "\n";
        }
    }
}

18.5 Known Limitations

  • Not a full Excel engine: array formulas (CSE), dynamic arrays (FILTER/SORT/UNIQUE), LET/LAMBDA, and macro-sheet functions are not supported
  • Unrecognized functions return 0 by default ($f->lenientUnknownFunctions = false changes this to return #NAME?)
  • TEXT() only implements common formats such as 0.00, #,##0.00, 0%, yyyy-mm-dd; complex custom formats degrade
  • Dates are handled with the 1900 date system (Excel for Windows); date1904 workbooks are not converted
  • Circular references return #CIRC!; it does not iterate to a solution the way Excel does

20. Image Extraction (Img Directory)

20.1 Two Image Sources

Source Characteristics Location Method
Floating images (Excel / LibreOffice) xl/drawings/drawing1.xml The <from><col><row> of twoCellAnchor / oneCellAnchor, 0-based
In-cell embedded images (WPS) xl/cellimages.xml + cell formula =DISPIMG("ID_xxx",1) Matched to the specific cell by ID_xxx

Both are supported.

20.2 Usage

$xlsx = SimpleXLSXPro::parse('demo.xlsx');

// Export to Img/ (relative to the current working directory), returns [sheet][row][col] => path
$map = $xlsx->extractImages('Img');

// Image list
foreach ($xlsx->imageList() as $img) {
    printf("%s  cell=%s  source=%s\n", $img['path'], $img['cell'], $img['source']);
}
// Img/sheet1_F3_1.png  cell=F3  source=xl/media/image1.png
// Img/sheet1_F8_2.png  cell=F8  source=xl/media/image2.png

// Look up by coordinate
echo $xlsx->imageAt(0, 5, 2);     // Img/sheet1_F3_1.png (col=5,row=2 means F3)

// Pass false as the second parameter to record absolute paths
$xlsx->extractImages('/var/www/uploads/Img', false);

20.3 File Naming Rules

Img/sheet{worksheet index}_{column letters}{row number}_{sequence}.{original extension}
Example: Img/sheet1_F3_1.png

When the same image is referenced in multiple places it is written to disk only once (there is an internal media cache), and the same path is returned for every reference.

20.4 Recording img Paths in Data

Both rowsPro() / toJSON(['cells'=>true]) carry an img field on cells:

foreach ($xlsx->readRowsPro(0) as $row) {
    foreach ($row as $c) {
        if ($c['img'] !== '') {
            // Insert straight into the DB: ['cell' => 'F3', 'img' => 'Img/sheet1_F3_1.png']
            $db->insert('cell_images', ['cell' => $c['name'], 'img' => $c['img']]);
        }
    }
}

Verified WPS embedded images (demo_wps.xlsx):

20.5 Notes

  • After successful extraction, the media entry is released via deleteEntry(), so large images do not stay in memory
  • Image extraction happens when extractImages() is called; if you do not call it, nothing is written to disk and no disk space is used
  • imageDir is relative to the current working directory; in web environments an absolute path is recommended
  • Only bitmaps inside xl/media/* are processed; legacyDrawing (VML comment images) and externally linked images (r:link) are not handled

Final Words

The value of SimpleXLSX lies in being just right: it does the job of "reading Excel" at 80 out of 100, at the cost of zero dependencies and being learnable with a single rows() call. The remaining 20 points (formula evaluation, charts, precise layout), if you need them, that is when you should switch to PhpSpreadsheet — but for most import scenarios, you don't need them.

The three most accident-prone points in daily use, once again:

  1. Number formats: leading zeros, ID numbers, long numbers — always set them as text at the Excel source;
  2. Formulas: not getting a value is normal — the library does not evaluate formulas;
  3. Security: before rendering user-uploaded xlsx files, href must be filtered by yourself, and the version must be >= 1.1.19.

This document was written based on a full read-through of the shuchkin/simplexlsx v1.1.19 source code plus hands-on testing with PHP 8.3.6. All conclusions marked "verified" were validated in a local environment.
